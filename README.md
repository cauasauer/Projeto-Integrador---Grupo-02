# Projeto-Integrador---Grupo-02
Grupo 2 — Transformers de visão

Visão Geral do projeto:

Desenvolver e avaliar modelos baseados em Vision Transformers (ViT) para auxiliar na detecção de câncer de mama a partir de imagens de mamografia, analisando seu desempenho e comparando diferentes arquiteturas e estratégias de treinamento.
